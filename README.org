#+title: Control de información para vehículos de CIETEL

* Introducción
Software para mantener un control (o al menos información actualizada) sobre los vehículos de CIETEL y sus respectivas reparaciones o mantenimientos.
* Idea principal
Un supervisor puede consultar la información de todos los vehículos de manera sencilla.
Al principio, al menos lo siguiente:
- [X] Información del vehículo (marca, modelo, placas)
- [X] Técnico asignado
- [X] Última fecha de servicio
- [ ] Registro de reparaciones

Visible en una página compuesta por HTML y CSS sencillo. Minimalista pero bien utilizable tanto en computadora como en móvil.

* Funcionamiento básico
- [X] Página principal (Una lista simple de todos los vehículos)
- [X] Seleccionar un vehículo y obtener su información completa en su propia página
- [ ] Ingresar vehículos
- [ ] Ingresar servicios
- [ ] Ingresar reparaciones
- [ ] Modificar información de vehículo
